# AI usage

FirstPass is developed with an AI coding assistant. This file records how it is used, so that readers can tell what was generated, what a human reviewed or changed, and how each part was checked.

## Tools

- **Assistant:** Claude Code (model Claude Opus 5.5), used in VS Code.
- **Role:** pair programmer. It proposes plans, writes code, tests and documentation, and checks facts against official documentation.

## Rules the assistant follows

- Every phase starts with a plan that the maintainer approves before any code is written.
- The maintainer creates every branch, commit, push and pull request. The assistant only writes files and suggests commands.
- The assistant never handles real credentials. Account setup, secrets and deployments are run by the maintainer.
- External APIs and pricing (AWS, GitHub, Gemini, Groq, HashiCorp) are checked against official documentation, never guessed.
- Domain code in `core` is written test-first (TDD).
- No change is called done while a test fails or is disabled.
